# 🌱 Ninaivu Thottam — Thirukkural 108

An interactive web experience inspired by Thirukkural 108.

## 📜 Thirukkural

**நன்றி மறப்பது நன்றன்று நன்றல்லது**  
**அன்றே மறப்பது நன்று**

## 💡 Concept

🌸 Flower = Remember good deeds  
🍂 Leaf = Release negative experiences  
🌱 Seed → Sprout → Bloom → Forest = Growth

## 🎮 How to Play

1. Open `index.html`.
2. Click **Enter Your Garden**.
3. Click **START GAME**.
4. Click 🌸 flowers to remember goodness.
5. Click 🍂 leaves to release negativity.
6. Your garden level grows as you make choices.

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript

## 🌟 Innovation

The project converts a Thirukkural message into an interactive experience instead of showing it as only static text.

**Remember goodness. Release negativity. Grow yourself. 🌱**
